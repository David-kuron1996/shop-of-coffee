### project Name ###

`Coffee Shop`: This project is a simple object-oriented model of a coffee shop, built in Python. It demonstrates the relationships between customers, coffees, and orders using classes and methods.

### Project files ###
The project is organized into three main Python files, each representing a core concept of the coffee shop:

`customer.py`: Defines the Customer class, which represents a person who can place orders.
`coffee.py`: Defines the Coffee class, representing the different types of coffee available.
`orders.py`: Defines the Order class, which links a Customer to a Coffee at a specific price.

### Installation and Setup ###
This project uses Pipenv for dependency management. It's a best practice to use a virtual environment to manage project dependencies.

1- **Install Pipenv** (if you don't have it).

`pip install pipenv`

2- **Navigate to the project directory in your terminal**

`cd path/to/your/coffee-shop project`

3- **Install the dependencies**

`pipenv install`
